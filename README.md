# TaskFlow 🗂️

Projeto de lista de tarefas (To-do List) desenvolvido para a empresa Task Flow.  
A aplicação representa um sistema de organização de tarefas.

---

## 💡 Sobre o projeto
O TaskFlow permite criar, editar, excluir e filtrar tarefas.  
As informações são salvas no navegador usando `localStorage`, então os dados não somem ao recarregar a página.

---

## 🚀 Funcionalidades
- Adicionar tarefas com prioridade
- Marcar como concluída
- Editar e excluir tarefas
- Buscar tarefas por nome
- Filtrar por status e prioridade
- Limpar tarefas concluídas
- Modo claro/escuro
- Barra de progresso com estatísticas

---

## 🛠️ Tecnologias
- HTML
- CSS
- JavaScript
- LocalStorage

---

## ▶️ Como usar
Basta clonar o projeto e abrir o arquivo `index.html` no navegador.

---

## 📌 Observação
Projeto feito com JavaScript puro, sem frameworks, para praticar lógica, DOM e manipulação de dados no front-end.
